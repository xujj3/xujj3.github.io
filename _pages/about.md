专注于**高导电材料与多尺度物理建模**研究，具备从微观电子输运（DFT/NEGF）到宏观电磁场/热场（COMSOL/HFSS）的跨尺度联合仿真经验。同时致力于结合大语言模型与 AI Agent 架构，推动材料科研数据与办公工作流的自动化。

---

## 🔬 核心研究方向

- **导电复合材料物理建模**：石墨烯-铜（Graphene-Copper）复合导体界面散射机理、微观结构设计与高频信号传输损耗分析。
- **跨尺度联合仿真与参数传递**：基于 Fuchs-Sondheimer (FS) 与 Mayadas-Shatzkes (MS) 理论，提取镜面反射率 $p$ 与晶界散射系数 $R_{\text{gb}}$，实现微观输运向 COMSOL / ANSYS HFSS 宏观求解器的参数自动传递。
- **材料 AI Agent 与科研自动化**：基于 MatClaw / OpenClaw 框架构建材料智能体平台，集成文献监控、RAG 私有知识库检索与自动化通知。

---

## 🚀 重点工程与科研项目

### 1. 高频低损耗复合导体跨尺度仿真平台
* **项目内容**：建立从微观电子输运到宏观电磁特性的多尺度计算链条。通过 QuantumATK 计算界面散射参数，联合 COMSOL / ANSYS HFSS 预测趋肤效应及高频衰减趋势。
* **成果产出**：实现跨尺度参数传递自动化，仿真与实验测量误差控制在 5% 以内。

### 2. 企业级材料 AI Agent 与科研自动化系统
* **项目内容**：基于 Agent 框架搭建自主材料 AI 平台，融合文献自动监控、RAG 知识库检索与飞书 API 提醒。
* **成果产出**：实现前沿文献每日自动摘要推送与内部仿真数据集的快速智能检索。
