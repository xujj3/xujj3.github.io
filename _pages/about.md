# 徐炯炯

**计算材料学 / 电子输运与多尺度建模**
*Computational Materials · Electron Transport and Multiscale Modelling*

金属材料工程师、仿真研究员，现任职于正泰集团。

研究方向为**石墨烯-铜复合导体中电子输运的微观机制及其向宏观模型的参数传递**，方法上结合第一性原理与量子输运计算（DFT / NEGF）与宏观输运模型。与之配套的工作是将文献获取、知识组织与数据提取的科研流程自动化，以降低机理研究中的非研究性时间开销。

---

## 研究框架

| | 主课题：电导率的微观机制 | 支撑工作：科研流程自动化 |
|---|---|---|
| **科学问题** | 石墨烯与铜各自的输运能力、界面电子散射行为、各散射机制对载流子迁移率的贡献 | 文献如何转化为可检索的知识、可计算的结构化数据、可交付的技术材料 |
| **方法** | DFT / NEGF 计算体相与界面的弹道及界面输运；引入散射机制并量化其对迁移率的影响 | 文献获取 → 语义分块与向量检索 → 字段抽取 → 报告生成 → 企业知识库调用 |
| **阶段产出** | 弹道输运上限、界面透射行为、各散射机制的相对贡献 | 一条可复现的自动化流程，及配套的培训与考核体系 |

二者并非并列的两项技能。机理研究的主要成本往往不在计算，而在信息的获取、整理与转述；支撑工作针对的正是这部分成本。

## 研究进展

| 阶段 | 状态 |
|---|---|
| 石墨烯与铜体相体系的弹道电导传输性质 | 已完成 |
| 石墨烯/铜界面电子输运计算 | 已完成 |
| 石墨烯常见散射机制对载流子迁移率的影响 | 已完成 |
| **界面散射理论**：将界面散射行为折算为宏观模型可用的参数（镜面反射率 *p*、晶界散射系数 *R*<sub>gb</sub>） | **进行中** |
| 参数代入宏观输运模型，与实验测量对照（含有限元 / 电磁仿真） | 待开展 |

第四阶段为当前工作位置。**该环节是整条研究链条中方法上最困难的一环**：前三个阶段的结论属"正向预测"，描述给定结构下将会发生什么；本阶段需要解决的是逆向映射——如何将量子输运结果转化为宏观模型可接受的唯象参数。

第五阶段拟采用的有限元与电磁仿真，是上述参数传递在本构关系层面上的延续，而非独立研究方向。值得指出的是，宏观仿真中材料参数通常取自手册值或实验拟合；本文所述路径自原子尺度起算，其优势在于参数具有明确的物理来源，微观与宏观之间不存在断点。

> 需明确说明：宏观仿真部分**目前尚无可以展示的算例**，故列为待开展，未计入已完成工作。
